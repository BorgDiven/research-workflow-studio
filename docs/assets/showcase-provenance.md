# Fictional desktop showcase

The walkthrough and `research-view.png`, `code-view.png`, and `comparison-view.png` depict a separate demonstration database created by `tools/seed_showcase.py`.

- Project names, questions, methods, cases, conclusions and reports are fictional examples.
- Geometric image assets are constructed in SVG. Curves and metric values are explicitly synthetic, manually specified examples, not measurements or evidence of method quality.
- Code descriptions illustrate reusable method interfaces. Missing execution or Git identity is not replaced with a fabricated verified commit.
- Screenshots and the walkthrough come from the actual desktop interface. They do not contain a user's research project, material directory, private source code, account or generated research images.
- The public demo seed refuses a database containing unrelated projects. Use a separate database for personal research.

The 1440 × 800 desktop walkthrough is recorded from actual interface operations, with frames encoded as a 24 fps MP4 and an 8 fps README GIF. It starts at the project home and visits research, code selection and output comparison. The video is an interface demonstration, not a record of an experiment being executed.

The title illustration has separate provenance in [banner-prompt.md](banner-prompt.md).

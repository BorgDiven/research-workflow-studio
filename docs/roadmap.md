# Roadmap

The 0.4 line extends the local research loop with training/process tracking, fixed evidence snapshots, repository/environment records and explicitly reviewed execution. The three-view workbench and human research decisions remain the organizing structure. Release acceptance and publication are tracked separately from implementation.

Future work is driven by concrete workflows:

- Additional adapters beyond explicit JSONL and selected MLflow metric history, with previewable mappings and unresolved provenance.
- Explicitly selected real-server integration checks beyond the current mocked SSH coverage.
- More typed visualizations for attention, trajectories and dataset-level metric coverage.
- English interface localization and accessibility refinement on desktop.
- Better incremental browsing for very large evidence collections.
- Optional client-specific MCP setup helpers and a reproducible demonstration walkthrough.

Automatic research decisions, unrestricted remote execution and a public multi-user hosted service are outside the current scope. Proposed features are not promises of an implemented capability.

# Roadmap

The 0.3 line focuses on a complete local research loop: project context, contract-first implementation, explicit provenance, bounded comparisons, scoped analysis and fixed reports.

Future work is driven by concrete workflows:

- Additional adapters for existing experiment formats, with previewable mappings and explicit unresolved provenance.
- More typed visualizations for attention, trajectories and dataset-level metric coverage.
- English interface localization and accessibility refinement on desktop.
- Better incremental browsing for very large evidence collections.
- Optional client-specific MCP setup helpers and a reproducible demonstration walkthrough.

Automatic research decisions, unrestricted remote execution and a public multi-user hosted service are outside the current scope. Proposed features are not promises of an implemented capability.

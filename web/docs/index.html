项目基础 → 研究问题 → 可复用实现 → 证据与比较 → 分析与报告。完成研究后可以提出基础修改建议，由你决定是否采纳。

从规则开始编写代码

先定义代码块的目的、输入、输出含义、配置项和验收条件，再登记实现的 Git 版本和检查证据。案例和常规参数放在输入中。同一实现可以用于不同研究问题。

产出、比较与报告

单案例查看多个设置，多案例对齐多个实现。按最终图、预测 clean、中间诊断、曲线或指标筛选。缺失结果留空，重复结果由你选择。分析说明证据范围和限制，报告固定当时输入。

人和模型各做什么

MCP 让模型读取上下文、登记工作和提出建议。它不运行程序、不启动 GPU，也不能代替人批准项目基础、阶段或科研结论。来源纠正通过审阅后的修订记录保留历史。

网页与 MCP 必须连接同一数据库。桌面浏览器可以通过配置好的 Tailscale 私有地址跨设备使用，未保存的表单不会自动同步。
